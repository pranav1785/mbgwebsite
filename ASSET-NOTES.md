Five transparent homepage previews were made with the built-in image generation tool in background-extraction edit mode. The original photographs remain in the assignment galleries. No new artwork was generated for the portfolio.

Saved outputs: `src/art/cutouts/bird.webp`, `sea.webp`, `vessel.webp`, `wire.webp`, and `rose.webp`.

The prompt set used this shared instruction, with the subject replaced for each input:

> Use case: background-extraction. Edit target: the supplied photograph. Create a precise photographic cutout of [subject] on a truly transparent background. Remove all table, fabric, hands, labels, paper, background objects and background shadows. Preserve the exact handmade artwork: same silhouette, proportions, surface texture, colours, imperfections, viewpoint and lighting. Do not redraw, improve, beautify or invent any part of the sculpture. No text. Centre the complete object with modest transparent padding. This is documentation of a student's real artwork; fidelity is essential.
